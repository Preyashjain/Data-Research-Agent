# Research Playbook

Use the Data Research Agent to handle questions in three phases:

1. Determine whether the question needs domain documentation or numeric analysis.
2. Use retrieval for architecture and process documentation.
3. Use SQL and calculator tools for metrics and comparisons.

## Typical workflows

### Retrieval-first questions

Examples:

- What does the deployment architecture say?
- What are the system responsibilities?
- How should a research workflow be structured?

### SQL-first questions

Examples:

- What was the average revenue in 2025?
- Compare the 2024 and 2025 revenue totals.
- Which region had the strongest conversion rate?

### Multi-step analysis

Examples:

- Compare the architecture described in the documentation with the observed business metrics.
- Calculate the percentage growth in revenue and explain it in context.
- Summarize research findings using both documentation and SQL evidence.

## Output expectations

Answers should be succinct, evidence-based, and clear about which tool produced each result.
